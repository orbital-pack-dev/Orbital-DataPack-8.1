## ⚙️ Раздел 1. Установка и Администрирование

### Установка

1. Положите папку `orbital_v7_1` в `<мир>/datapacks/`.
2. Зайдите в игру и выполните `/reload`.
3. Проверьте, что пак подхвачен: `/datapack list`.

### Основные команды

| Команда | Назначение |
|---|---|
| `/reload` | Перезагрузка пака. Запускает `nuke:load` — создаются объективы и подтягиваются сохранённые флаги |
| `/function nuke:settings/menu` | Главное меню настроек (диалоговое окно с кнопками) |
| `/function nuke:settings/reset` | Сброс всех настроек к заводским значениям |
| `/function nuke:settings/info` | Вывод текущих значений всех флагов в чат |
| `/function nuke:give/all` | Выдать себе весь комплект контента (для тестов) |
| `/function nuke:give_recipes` | Выдать игрокам рецепты пака в книгу рецептов |

### Система переключателей `nuke.config`

Все глобальные флаги хранятся в отдельном скорборде `nuke.config`.
Меню (`nuke.settings`) — это то, что крутит игрок; `nuke.config` — то, что реально читает логика взрывов.
Значения переживают `/reload` и перезапуск сервера.

| Флаг | Значения | Описание |
|---|---|---|
| `#block_protection` | `0` / `1` | **Защита блоков.** `0` — взрывы физические, воронки реальные. `1` — урон только по сущностям + частицы, блоки целы |
| `#orbital_enabled` | `0` / `1` | **Тумблер Орбитального комплекса.** `0` — все орбиталки отключены, рецепты отзываются |
| `#orbital_nerf` | `0` / `1` | Ослабленный режим: урон орбиталок режется вдвое |
| `#personal_cd` | `0` / `1` | Персональный кулдаун вместо общего серверного |
| `#vip` | `0` / `1` | Выстрелы без списания опыта |
| `#wither_skulls` | `0` / `1` | Разрешить черепа визера в ударе NUKE |
| `#stab_cd` / `#nuke_cd` / `#wither_cd` / `#mortar_cd` / `#archi_cd` | тики | Кулдауны каждого орудия (0–1200) |
| `#bv_time` | тики | Таймер Подрывного Жилета (по умолчанию 640 = 32 сек) |
| `#tt_scale` | тики | Масштаб «часа» для Таймер-ТНТ (по умолчанию 1200) |

#### 🔒 `#block_protection` — Защита блоков

Единый взрывной гейт для всего пака: Жилет, Таймер-ТНТ, Fire-Shot, Гасты и орбиталки
спрашивают один и тот же флаг перед каждой детонацией.

| Значение | Что происходит |
|---|---|
| `0` — Защита ВЫКЛ | Спавнится настоящий `minecraft:tnt` с `fuse:0s`. Полноценные воронки и разрушение рельефа |
| `1` — Защита ВКЛ | Ни одного физического взрыва. Урон выдаётся через `damage`, визуал — через частицы |

> Дополнительно работает страховочный тик-перехватчик: любой ТНТ с тегами `nuke_boom`, `tt_boom`,<br>`fs_boom`, `bv_boom` при включённой защите автоматически переводится в безопасный режим.

#### 🛰️ `#orbital_enabled` — Отключение Орбитального комплекса

При `#orbital_enabled = 0`:

- тиковые функции `Nuke`, `Stab`, `Wither` и `Fire-Shot` выходят через `return 0` в самом начале;
- начатая попытка выстрела сбрасывается (`abort_shot`), снаряд не уходит;
- рецепты орбиталок отзываются у всех игроков;
- **в Выживании** пушка ломается прямо в руках (`break_cannon`);
- **в Креативе** предмет остаётся цел — режим тестов для админов.

```mcfunction
scoreboard players set #orbital_enabled nuke.config 0
scoreboard players set #block_protection nuke.config 1
```

## 💣 Раздел 2. Механики и Предметы

### 🔭 Орбитальные Пушки

Все три пушки — это удочки (`fishing_rod`) с кастомными компонентами.
ПКМ → луч прицеливания (raycast) ищет точку попадания → спустя задержку с неба приходит удар.

| Пушка | Редкость | Что делает | Заряды и урон | Кулдаун | Цена в XP |
|---|---|---|---|---|---|
| **Stab-Shot** | `rare`, аква | Точечный прокалывающий удар по одной точке. Самый быстрый и дешёвый выстрел | Компактная серия зарядов в одну точку, малый радиус поражения | 200 тиков (10 сек) | 10 уровней |
| **Nuke-Shot** | `epic`, красный | Ковровая бомбардировка по площади. Главный калибр пака, апгрейдится в 4 этапа (P1–P4) | Центральный снаряд + веер дочерних боеголовок; с каждым апгрейдом число зарядов и площадь растут | 600 тиков (30 сек) | 30 уровней |
| **Wither-Shot** | `epic`, фиолетовый | Залп визера: черепа + иссушение в зоне поражения | Серия визерских черепов по точке прицела; черепа вкл/выкл флагом `#wither_skulls` | 300 тиков (15 сек) | 25 уровней |

> **Общие правила для всех пушек:**
> • Выстрел списывает опыт, если не включён `#vip`.<br>
> • При `#orbital_nerf = 1` весь урон режется вдвое (80 → 40).<br>
> • При `#block_protection = 1` урон по сущностям сохраняется, а блоки остаются целы.<br>
> • При `#orbital_enabled = 0` выстрелы невозможны вообще.

### 🦺 Подрывной Жилет — `blast_vest`

Кольчужный нагрудник с проклятием привязки — снять его нельзя.

| Параметр | Значение |
|---|---|
| Таймер | 640 тиков = **32 секунды** (настраивается через `#bv_time`) |
| Запуск | Автоматически при надевании |
| Досрочный подрыв | **Shift** — мгновенная детонация |
| Звуковое оповещение | Тиканье каждую секунду, учащающееся к финалу, + обратный отсчёт на экране |
| Радиус поражения | 6 блоков |
| Зачёт убийств | Автором взрыва считается носитель — лут с мобов падает |
| Защита блоков ВЫКЛ | Центральный заряд + 4 по краям — глубокая воронка |
| Защита блоков ВКЛ | Только урон по сущностям + частицы |

### 🛡️ Архи-Щит — `archi_shield`

| Режим | Поведение |
|---|---|
| Пассивно | Лёгкий визуал `end_rod` у ног — не мешает обзору |
| **Shift** — барьер | Купол из частиц + надпись «✦ АРХИ-ЩИТ: БАРЬЕР АКТИВЕН ✦» |
| Отражение снарядов | Радиус 4 блока, **7 типов**: стрелы, спектральные стрелы, трезубцы, фаерболы, малые фаерболы, черепа визера, фаерболы Дракона |
| **Физическая АОЕ-атака** | Радиус **3.5 блока**, 6 единиц урона типа `player_attack` — с полноценным отбрасыванием от владельца и дополнительным подбросом вверх |
| Прочность | 1680 единиц |

> Убийства от атаки щита засчитываются игроку, поэтому с мобов корректно падает лут и опыт.

### ⏱️ Таймер-ТНТ — `timer_tnt`

Закладка с отсрочкой от 1 до 4 часов реального времени.

| Механика | Описание |
|---|---|
| Визуал | `block_display` с текстовой голограммой и живым обратным отсчётом |
| **Непроницаемый хитбокс** | Невидимый **Магма-Куб**: 1024 ХП, броня 30, неуязвимость, нулевая скорость и урон, пустая таблица лута |
| Привязка | Каждый тик куб жёстко центруется по позиции заряда — его нельзя сдвинуть |
| Снятие коллизии | **За 20 тиков (1 секунду) до детонации** куб уводится в void и только там умирает — мелкие кубы в мире не появляются |
| Разрядка | Любая вода в клетке заряда или на любой из 6 его граней — заряд обезвреживается |
| Детонация | Честный ванильный взрыв `minecraft:tnt` с `fuse:0s`, если `#block_protection = 0` |

### 👻 Гасты с ТНТ — `happy_ghast`

Живая управляемая авиабомба. На Доброго Гаста можно навешать заряды.

| Механика | Описание |
|---|---|
| Зарядка | От **1 до 14 ТНТ**, счётчик `ghast_tnt`. Каждый заряд отображается отдельным `block_display` на тушке |
| Частицы заряда | Волны частиц с тремя ступенями интенсивности: 1–4, 5–9, 10–14 зарядов |
| Динамический сброс | При срабатывании Гаст сбрасывает ровно столько предметов ТНТ, сколько было навешано |
| **Пропорциональный взрыв** | При получении урона спавнится **столько же зарядов ТНТ, сколько навешано**: 14 ТНТ = 14 реальных взрывов, а не один |
| Раскладка зарядов | Крестом вокруг точки детонации — воронка растёт и вширь, и вглубь |
| Радиус урона | 8 блоков от тушки |

### 🚀 Ракета Fire-Shot (Орбитальная Мортира) — `fire_shot`

Арбалет, заряженный орбитальной ракетой.

| Механика | Описание |
|---|---|
| **Фиксированная траектория** | Вектор взгляда запоминается в момент выстрела. Ракета НЕ следит за камерой и не петляет |
| Звук | Двигатель слышен раз в 15–20 тиков (через `modulo`) — тихо, без спама |
| Финальный взрыв | Урон **80** в радиусе **20 блоков** (или 40 при включённом нерфе) |
| **Воронка** | **5 зарядов**: центральный мгновенно + 4 крестом на расстоянии 2 блоков |
| Защита блоков ВКЛ | Урон по радиусу остаётся, воронка не создаётся |

### 🔐 Сейф с паролем — `safe_chest`

| Механика | Описание |
|---|---|
| Установка | Поставьте Сундук с Паролем → сразу запускается мастер установки пароля |
| Ключ | Крючок-растяжка с меткой `nuke_key_active`; заготовки ключей прошиваются под конкретный сейф |
| **Полная защита блока** | Сущность `interaction` со смещением `~-0.2` и габаритами **1.2×1.4** (одиночный) или **2.2×1.4** (большой сундук) — низ сундука не пробить |
| Соседние сундуки | Попытка склеить чужой сундук с сейфом блокируется |
| **Авто-закрытие** | Как только ближайший игрок отошёл **дальше 4 блоков** — замок возвращается, `interaction` заново садится на блок |
| Слом | При разрушении сундука вся техника сейфа корректно убирается |

### 🧪 Зелье Сытости — `potion_of_saturation`

Золотое зелье «✦ Зелье Сытости ✦», редкость `rare`.

| Эффект | Длительность | Уровень |
|---|---|---|
| Регенерация | 3600 тиков = **3 минуты** | I |
| Насыщение | 240 тиков = **12 секунд** | II |

Время выпивания — 1.6 секунды. Одно зелье полностью закрывает шкалу голода
и даёт трёхминутное восстановление здоровья — боевая аптечка перед штурмом.

## 📜 Раздел 4. Правила Использования на Сервере

> Нарушение любого из пунктов ниже — основание для изъятия предметов, отката региона или блокировки.

### 1. Орбитальные Пушки

- ❌ **Запрещено** применять орбиталки по чужим постройкам, фермам и торговым точкам без согласия владельца.
- ❌ **Запрещены** выстрелы в спавне, на торговой площади и в публичных зонах.
- ❌ **Запрещены** массовые серийные залпы ради лага сервера.
- ✅ **Разрешено** на согласованных PvP-событиях, войнах кланов и на собственной территории.
- ✅ Если администрация выключила `#orbital_enabled` — пушка ломается в руках. Это не баг, компенсация не выдаётся.

### 2. Заминированные Гасты

| Лимит | Значение |
|---|---|
| Зарядов на одного Гаста | не более **14** (жёсткий потолок механики) |
| Заминированных Гастов на игрока | не более **2** одновременно |
| Заминированных Гастов на клан/базу | не более **5** одновременно |
| Запретные зоны | Спавн, торговая площадь, публичные порталы и хабы |

- ❌ Запрещено оставлять заминированного Гаста без присмотра в чужом регионе.
- ❌ Запрещено использовать Гастов как «мину-ловушку» на публичных дорогах.
- ✅ Перед вылетом убедитесь, что рядом нет незаинтересованных игроков.

### 3. Регламент защиты блоков

| Режим | Когда включается | Что можно |
|---|---|---|
| `#block_protection = 1` (по умолчанию на мирном режиме) | Обычные будни сервера | Вся взрывчатка работает как оружие по сущностям, ландшафт и постройки не страдают |
| `#block_protection = 0` | Только на объявленных войнах, ивентах и осадах | Полноценные воронки, разрушение построек в рамках правил ивента |

- Переключать флаг вправе **только администрация**.
- Все воронки, полученные при `#block_protection = 0`, восстановлению не подлежат.
- Требование отката региона после объявленного ивента не принимается.

### 4. Общие правила

- ❌ Запрещён гриф чужих сейфов через баги, дюпы и обход `interaction`.
- ❌ Запрещена намеренная перегрузка сервера массовыми детонациями.
- ✅ О найденных багах сообщайте в поддержку — за баг-репорт возможно поощрение.
